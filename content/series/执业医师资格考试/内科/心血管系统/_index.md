## 心衰


```mermaid
flowchart TD
    hf[心衰]

    hf -- 房颤/心脏扩大/低血压 ---> ydh[洋地黄] --> zd[中毒]
    zd -- 最常见 --> a[心律失常（室早二联律，室性心动过速），忌用直流电复律]

    hf -- 高血压 ---> xpn[硝普钠]

    hf -- 血压正常/肾衰 --> 呋塞米

    c1[急性心梗 24 小时内] --x ydh
    c2[急性左心衰] --x bjk[β 受体拮抗剂（美托洛尔）（负性肌力）]
    c3[高血压急症] -- 静滴 ---> xpn
```

- 血压低，我电击（室颤同步，其余非同步)
- 看到缓慢用阿姨 (阿托品异丙肾) 
- 看到室性利多安（利多卡因胺碘酮) 
- 室上速，腺帕酮 （腺苷，维拉帕米，普罗帕酮)
- 普通预激同室上（腺帕酮)
- 旁路预激要消融 (射频消融)


起搏器 》 心房充盈，释放心房钠尿肽 》 外周血管舒张 》 血压降低

```mermaid
flowchart TD
    sss[阵发性室上速] --> xs{{合并心衰？}}
    xs -- 是 ---> t1[同步直流电复律（洋地黄中毒禁用）]
    xs -- 否 --> t2[腺苷，维拉帕米，普罗帕酮]

    sss -- 根治 --> t3[旁路消融]

    yj[预激综合征] --> qrs{{QRS 波}}
    qrs -- 正常，顺向 AVRT --> t2
    qrs -- 宽大畸形，逆向 AVRT --> t4[依布利特、普鲁卡因胺、普罗帕酮]
    qrs -- "`不可辨认（**房颤/室颤**）`" ---> t5[非同步直流电除颤]

    sxq[室性期前收缩（QRS 宽大畸形）] --> dxy{{收缩压 < 90 mmHg}}
    dxy -- 是 --> t1

    dxy -- 否 ---> pf{{有症状？}}
    pf -- 否 --> sz[无需治疗]
    pf -- 是 --> qz{{器质性病变？}}

    qz -- 有 --> bjk[胺碘酮]
    qz -- 无 --> ldky[利多卡因]

    sxq --> ts{{特殊类型}}
    ts -- 加速性室性自主节律 --> byz[无需治疗]
    ts -- 尖端扭转型 --> mg[静脉注射镁盐]


    t1 & t5 --> eng(["单相（直流）首次 360J\n双相（交流）首次150~200J"])
```

```mermaid
flowchart TD
    高血压 --> hb{{合并}}
    hb -- 窦性心动过速 --> bjk[β 受体拮抗剂（美托洛尔）（负性肌力）]
    hb --- xjt[心绞痛]
    xjt -- 稳定型/劳力型：ST 压低 ---> bjk
    xjt -- 变异型：ST 一过性抬高 ---> ca[钙离子通道拮抗剂（CCB）]

    hb -- 糖尿病/肾功能不全（蛋白尿）/左室肥大；\n且血肌酐 < 265 μmol/L、无肾动脉狭窄、无高血钾、非妊娠 --> acei[ACEI /ARB类]

    acei --> hy{{合用}} -- 心率较快 --> bjk
    hy -- 轻中度高血压，且无痛风 --> sq[噻嗪类利尿剂]
    hy -- 老年 --> ca

    bjk --> bjkty[出现二度、三度房室传导阻滞，应将剂量减到 ≤ 25 mg 后停药]
```
